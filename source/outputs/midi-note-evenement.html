02 / MIDI · 5 MIN DE LECTURE

Une note est un événement.

En MIDI, la durée d’une note se lit entre deux événements : Note On la déclenche, Note Off marque sa fin.

Cahier 02 · Les gestes numériquesdéclenchement · relâchement · durée

01 / LE DÉBUT ET LA FIN

Une note se joue dans le temps.

Quand tu enfonces une touche, l’instrument reçoit un événement Note On. Quand tu la relâches, il reçoit un événement Note Off pour la même note et le même canal. La vélocité du Note On décrit la force de départ ; le message Note Off peut aussi transporter une vélocité de relâchement, même si beaucoup d’usages courants n’en tirent pas parti.

Le message de départ ne dit donc pas à lui seul « joue cette note pendant une seconde ». La durée apparaît parce qu’un événement de fin survient plus tard. Pour une phrase jouée en direct, le temps écoulé entre les deux gestes définit la durée demandée.

À retenir — Note On marque un départ ; Note Off marque une fin. C’est leur écart dans le temps qui donne la longueur de la note.

02 / À L’ÉCOUTE

Maintiens la note, puis relâche-la.

Garde le bouton « Note On » enfoncé pour tenir la note ; relâche-le pour envoyer Note Off. Au clavier, maintiens Espace ou Entrée. Le son est synthétisé dans cette page ; aucun message ne part vers un appareil MIDI externe.

Les événements ne sont pas l’enveloppe.

Relâcher la touche ne signifie pas toujours que le son s’arrête net. Un synthétiseur peut appliquer une phase de release à son enveloppe, puis laisser le signal décroître. La note MIDI a reçu sa fin ; le timbre et la conception de l’instrument déterminent comment cette fin se fait entendre.

03 / DANS UNE SÉQUENCE

Le séquenceur garde aussi le placement.

Dans une séquence, les événements sont associés à des positions temporelles. Un fichier MIDI standard peut conserver des données MIDI horodatées, ainsi que des informations comme le tempo et la mesure. Le séquenceur peut alors rejouer les notes dans le bon ordre et au bon moment.

Si tu déplaces Note Off plus loin, la note demandée s’allonge. Si tu déplaces Note On, son départ change de place. La grille, le tempo et les réglages de quantification aident à organiser ces positions, mais ils ne remplacent pas les événements de départ et de fin.

Pourquoi deux fichiers sonnent-ils différemment ?

Une séquence MIDI peut être jouée par différents instruments ou presets. Les notes et leurs placements peuvent rester identiques, tandis que l’enveloppe, le son de base ou le relâchement du nouvel instrument changent le résultat audible. Les événements décrivent l’interprétation ; l’instrument lui donne sa couleur.

Repère : dans le fichier ou le séquenceur, tu peux examiner les événements et leur placement. Dans l’instrument, tu règles la façon dont le son réagit à ces événements.

04 / POUR LA SUITE

Écoute ce que change la longueur.

Fais deux essais : une note courte, puis une note tenue. Observe l’écart entre les deux événements et la façon dont le son s’éteint après le relâchement. Dans la prochaine note, nous suivrons le message jusqu’à sa destination : le bon canal, la bonne piste et le bon instrument.
